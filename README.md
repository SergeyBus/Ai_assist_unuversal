# Ai Assist Universal

## Описание
Универсальный AI-ассистент для управления сервисом: клиенты, записи на услуги, база данных.

## Функциональность
- Управление базой данных клиентов
- Система записей на услуги
- API для интеграции
- REST endpoints для управления данными

## Стек технологий
- Python 3.9+
- Flask/FastAPI
- SQLite/PostgreSQL
- Telegram Bot API

## Установка
```bash
git clone https://github.com/SergeyBus/Ai_assist_unuversal.git
cd Ai_assist_unuversal
pip install -r requirements.txt
```

## Использование
```bash
python app.py
```
